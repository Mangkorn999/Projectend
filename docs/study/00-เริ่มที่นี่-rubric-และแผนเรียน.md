# เริ่มที่นี่ — เป้าหมายคือ A ทุกหัวข้อ

ชุดเอกสารนี้เขียนให้ **มังกร (Backend + Database)** อ่านแล้วเข้าใจโปรเจกต์ทั้งระบบ (frontend + backend)
ตั้งแต่ศูนย์ จนอธิบายโค้ดและแก้โค้ดสดต่อหน้ากรรมการได้ — เขียนเฉพาะสิ่งที่มีอยู่ในโค้ดจริงของโปรเจกต์นี้

> ปรับปรุง 1 ต.ค. 2569 · สอบปลายภาค 14 ต.ค. 2569 · ต้องเสร็จก่อน 10 ต.ค. → เหลือ 9 วัน (2–10 ต.ค.)
>
> **อัปเดต 1 ต.ค.:** ระบบเปลี่ยน 5 เรื่อง — (1) แนบหลักฐานได้หลายไฟล์ PDF/JPG/PNG ≤ 5 ไฟล์ ตรวจชนิดจากไบต์ต้นไฟล์ + ลบทีละไฟล์ (2) ใบที่ถูกตีกลับแก้ส่งใหม่ได้แม้รอบปิด (`findSubmittableRound`) (3) แก้บั๊ก B1 (วิชาที่ยกมาจากใบที่ถูกตีกลับภายหลังเคยถูกนับว่าผ่าน) (4) ส่งออกรายชื่อ "ผ่าน/ไม่ผ่านภายในปีแรก" (5) บทบาท reviewer เรียกบนจอว่า "ผู้ช่วยตรวจสอบ" — ไฟล์ 00–07 ปรับตามแล้ว และเพิ่มไฟล์ใหม่ **08–12**

## 1. Rubric ของอาจารย์ → ต้องทำอะไรถึงได้ A

| หัวข้อ | คะแนน | เกณฑ์ระดับ A (ย่อ) | สิ่งที่ต้องมีจริง | ไฟล์ในชุดนี้ |
|---|---|---|---|---|
| 1. โปสเตอร์นำเสนอ | 10 | ครบถ้วน สวยงาม เป็นอาชีพ สื่อสารปัญหา วิธีดำเนินงาน ผลลัพธ์ ประโยชน์ได้โดดเด่น | โปสเตอร์ที่เล่าเรื่องครบ 5 ส่วน | `07` |
| 2. ความเข้าใจ อธิบาย และปรับปรุง Source Code | 25 | อธิบายโครงสร้างระบบและโค้ดได้ลึกซึ้ง **แก้ไข/เพิ่มฟังก์ชันตามที่กรรมการกำหนดได้ทันที** | อธิบายได้ว่าโค้ดไหลยังไง + เคยซ้อมแก้โค้ดสดมาแล้ว | `01` `02` `03` `04` `05` **`08`** `10` `11` |
| 3. ความสมบูรณ์ตาม Scope | 30 | ทำได้ 91–100% ของ Scope ใช้งานได้จริง **มีความเสถียรสูง** | ตาราง Scope ครบทุกข้อ + ไม่มี bug ตอนเดโม | หัวข้อ 3 ด้านล่าง + `07` |
| 4. การนำเสนอและเดโมโปรเจค | 10 | นำเสนออย่างมืออาชีพ เดโมราบรื่นมาก มีข้อผิดพลาดเล็กน้อย | สคริปต์เดโมที่ซ้อมแล้ว + ข้อมูลเดโมพร้อม | `07` |
| 5. ตอบคำถามกรรมการ | 25 | ตอบถูกต้องครบถ้วน อธิบายหลักการ เทคนิค อัลกอริทึม วิเคราะห์ข้อมูลได้ลึกซึ้ง | เตรียมคำตอบหลักการ "ทำไมเลือกแบบนี้" | `06` **`09`** **`12`** |

**ข้อสังเกตสำคัญ:** หัวข้อ 2 + 5 (รวม 50 คะแนน) วัดที่ "ความเข้าใจ" ไม่ใช่ปริมาณฟีเจอร์. ฟีเจอร์นอก Scope ไม่ได้คะแนนเพิ่ม
แต่ bug ตอนเดโมเสียทั้งหัวข้อ 3 และ 4. ดังนั้นเวลาที่เหลือควรใช้กับ **ความเข้าใจ + ความเสถียร** มากกว่าเพิ่มของใหม่.

## 2. แผนเรียน 9 วัน (2–10 ต.ค.) และแผนที่ไฟล์

**ตารางเรียนรายวันอยู่ที่ `11` หัวข้อ "ตารางเรียน 9 วัน"** (จับคู่ไฟล์ 00–12 กับแบบฝึกหัดรายวัน)

| ไฟล์ | ใช้ทำอะไร | rubric ข้อ |
|---|---|---|
| `01` พื้นฐานจากศูนย์ | เว็บ/HTTP/DB/ความปลอดภัย/JS/React ระดับภาพรวม | 2, 5 |
| `02` ภาพรวมระบบ | โฟลเดอร์ ตาราง วงจรสถานะ | 2, 5 |
| `03` backend logic | กฎธุรกิจทุกเรื่อง + เหตุผล | 2, 5 |
| `04` frontend logic | app.jsx, api.js, หน้ากรอกผลหลายไฟล์, แจ้งเตือน | 2 |
| `05` ฝึกแก้โค้ดสด | 15+ โจทย์แบบละเอียด (เฉลยในตัว) | 2 |
| `06` คลังคำถาม | 70+ คำถามพร้อมแนวตอบ | 5 |
| `07` เดโม/โปสเตอร์ | สคริปต์เดโม เช็คลิสต์วันสอบ | 1, 3, 4 |
| **`08` แผนที่จุดแก้โค้ด** | **45 โจทย์ "กรรมการสั่ง X → ไฟล์ไหน ฟังก์ชันไหน แก้อะไร พิสูจน์ยังไง"** | **2** |
| **`09` อัลกอริทึมทีละบรรทัด** | **12 อัลกอริทึมหลัก พร้อมตาราง trace และคำถามกรรมการ** | **5** |
| `10` JS/React ผ่าน if-for | ทุกท่าที่โปรเจกต์ใช้ แปลงเป็น if/for + แบบฝึก | 2 |
| `11` แบบฝึกหัด | 29 ข้อ 3 ระดับ + เฉลย + ตาราง 9 วัน | 2 |
| **`12` ซ้อมสอบปากเปล่า** | **5 ชุดคำถามต่อเนื่อง + คำตอบระดับ A** | **5** |

ถ้าเวลาเหลือน้อยมาก ให้ทำ 3 ไฟล์นี้ก่อน: **`08` (บอกไฟล์ให้ได้ทุกข้อ) → `09` (หัวข้อ 5–9) → `12`**

**วิธีอ่านให้จำได้ (สำคัญกว่าอ่านให้จบ):**
1. อ่านทีละหัวข้อ แล้ว **ปิดเอกสาร** พูดออกเสียงอธิบายให้เพื่อน (หรือกระจก) ฟัง ถ้าติดตรงไหน = ตรงนั้นยังไม่เข้าใจ
2. ทุกหัวข้อมี "ไปเปิดดูโค้ดจริง" — เปิดไฟล์นั้นใน VS Code ตามที่ระบุ อย่าอ่านแค่เอกสาร
3. ข้อ 05 (ฝึกแก้โค้ด) ต้องพิมพ์โค้ดเองจริง ๆ ไม่ใช่อ่านเฉลย — กรรมการให้แก้สด ไม่ได้ให้ท่องจำ

### ข้อจำกัดที่ต้องเตรียมคำตอบไว้ (กรรมการมักถาม)
- ตั้งใจใช้ PSU One Passport แต่ขอ credential ไม่ได้ → ระบบออก JWT เองและเก็บรหัสเป็น bcrypt hash (ดู `06` ข้อ 1)
- ลบบัญชีเจ้าหน้าที่ที่เคยทำงานแล้วไม่ได้ (FK RESTRICT) — ใช้ "ถอนสิทธิ์" แทน (ดู `06` ข้อ 38)
- rate limit เก็บใน memory ของ process เดียว (พอสำหรับ deploy เครื่องเดียว; ถ้าหลายเครื่องต้องใช้ Redis)
- ยังไม่ deploy ขึ้น server จริง (สาธิตในเครื่อง) → ต้องตั้ง `COOKIE_SECURE=true` ตอนขึ้น HTTPS
- ใบที่ถูกตีกลับหลังปิดรอบแก้ได้โดยยังไม่มีเส้นตาย (จนกว่าจะมีรอบใหม่ของรุ่น) — เพิ่มได้ถ้าคณะต้องการ (`08` ข้อ C3)
- JWT ยกเลิกรายใบไม่ได้ (logout ลบแค่ cookie) — ตัดได้ทันทีเฉพาะเมื่อถอนสิทธิ์/ลบบัญชี
- ข้อสังเกตจากเทส (`docs/test-report.md` N1): นักศึกษาเรียก `GET /api/rounds` เห็นรายการรอบทุกรุ่น (ข้อมูลไม่ลับ) — รอตัดสินใจ วิธีปิดอยู่ที่ `08` ข้อ B6
