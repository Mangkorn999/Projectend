# 11 — แบบฝึกหัด 29 ข้อ (3 ระดับ) + เฉลย + ตารางเรียน 9 วัน

**กติกาการฝึก**
1. อ่านโจทย์ → **ปิดเฉลย** → ลงมือเอง จับเวลา (ระดับ 1 ≤ 5 นาที · ระดับ 2 ≤ 10 นาที · ระดับ 3 ≤ 20 นาที)
2. ทุกข้อต้อง **พิสูจน์** ตามช่อง "ตรวจคำตอบด้วย" ไม่ใช่แค่ "คิดว่าถูก"
3. ฝึกเสร็จทุกข้อ คืนโค้ด: `git checkout -- <ไฟล์ที่แก้>` (ดูรายชื่อไฟล์ที่แก้ด้วย `git status` — ห้าม `git add .`)
4. **ห้ามบันทึกอะไรลงข้อมูลเดโม:** ยิง curl ได้เฉพาะ GET และคำขอที่ควรถูกปฏิเสธ (400/403/429) · การบันทึกจริงพิสูจน์ด้วย `npm run test:clean`
5. แก้ backend แล้ว **restart `npm start`** ทุกครั้ง

คำสั่งที่ใช้บ่อย (จากโฟลเดอร์ `backend/`):
```bash
curl -c cj.txt -X POST localhost:3000/api/auth/login -H "Content-Type: application/json" -d "{\"psu_passport_id\":\"456\",\"password\":\"456\"}"
curl -b cj.txt localhost:3000/api/...           # เรียกต่อด้วย cookie
ONLY=phase24 npm run test:clean                  # เทสไฟล์เดียวบนฐานข้อมูลชั่วคราว
```

### ข้อ 7 นับผ่านครั้งแรก/ปีแรก
รุ่น 4 คน วิชา [A,B] (ทุกใบที่พูดถึงยืนยันแล้ว เว้นแต่บอกไว้):
- P: รอบ 1 A✓B✓
- Q: รอบ 1 A✓B✗ · รอบ 2 B✓
- R: รอบ 1 A✓B✓ แต่ **รอตรวจ** (ยังไม่ยืนยัน)
- S: รอบ 1 A✗B✗ · รอบ 2 A✓B✓ แต่ **ถูกตีกลับ**
หาค่า ผ่านครั้งแรก และ ผ่านภายในปีแรก (จำนวนและร้อยละ 2 ตำแหน่ง)

# ระดับ 3 — เพิ่มฟังก์ชัน (7 ข้อ)

### ข้อ 23 ★★★ endpoint ประวัติการตรวจ
`GET /api/exam-results/:id/logs` (เจ้าหน้าที่เท่านั้น) คืนรายการ `review_logs` ของใบนั้น พร้อมชื่อผู้ตรวจ เรียงเก่า→ใหม่
**ตรวจคำตอบด้วย:** `curl -b cj.txt localhost:3000/api/exam-results/<id>/logs` → 200 · id ไม่มีจริง → 404 · ไม่มี cookie → 401 · ผู้บริหาร → 403

### ข้อ 24 ★★★ endpoint สรุปจำนวนใบในรอบ
`GET /api/rounds/:id/summary` → `{ round_id, total, pending, approved, rejected }`
**ตรวจคำตอบด้วย:** curl ด้วย id รอบจริง แล้วเทียบตัวเลขกับแท็บในหน้าคิวตรวจของรอบเดียวกัน (ต้องตรงกัน)

### ข้อ 25 ★★ ตัวเลขใหม่บนแดชบอร์ด
การ์ด "ยังไม่เปิดสิทธิ์กรอก" = ทั้งรุ่น − ที่เปิดสิทธิ์แล้ว (คำนวณที่ backend)
**ตรวจคำตอบด้วย:** `curl -b cj.txt localhost:3000/api/dashboard/stats` เห็นช่องใหม่ → หน้าแดชบอร์ดเห็นการ์ด · สลับ EN แล้วไม่เห็นชื่อคีย์ดิบ

### ข้อ 26 ★★ ตัวกรอง "ผ่านครบ / ยังไม่ผ่านครบ"
ในหน้าข้อมูลนักศึกษา + เปลี่ยนตัวกรองแล้วกลับหน้า 1 + ปุ่มส่งออกได้ไฟล์ตามที่กรอง

### ข้อ 27 ★★ คอลัมน์ใหม่ในไฟล์รายชื่อผ่าน/ไม่ผ่าน

**ตรวจคำตอบด้วย:** ส่งออกทั้ง 2 ไฟล์จากเมนูส่งออก เปิดดู · `ONLY=phase22 npm run test:clean` fail ที่ "หัวคอลัมน์ครบ" → แก้เทสให้ผ่าน
