- **รหัส** `PHxx-nn` = เทส API อัตโนมัติ (`backend/tests/smoke-phaseXX-*.mjs`) · `WEB-nn` = เทสผ่านหน้าเว็บจริงด้วย Chrome (`backend/tests/e2e/real-flow.e2e.mjs`)
- **บทบาท**: นศ. = นักศึกษา · จนท. = เจ้าหน้าที่คณะ (officer) · ผช. = ผู้ช่วยตรวจสอบ (reviewer) · ผบ. = ผู้บริหารคณะ (executive)
- ทุกเทสรันบนฐานข้อมูลชั่วคราว (schema แยก) ไม่แตะข้อมูลจริง 928 คน

  - หน้าเว็บ: `cd backend && npm run test:e2e` (พอร์ต 3200/5175, schema `verify_e2e`)
- เทส phase 1–25 สรุปเป็นกลุ่มต่อไฟล์ (ชื่อ check จริงอยู่ในไฟล์) · phase 26 และเทสหน้าเว็บที่เพิ่มรอบนี้เขียนละเอียดรายข้อ
