# ตารางสรุปผลสอบผ่านครั้งแรก จำแนกรายวิชา

วันที่ออกแบบ: 2026-08-12

## ปัญหา

คณะต้องส่งตารางนี้ให้สภาการพยาบาลทุกปี (ตารางที่ 1 ในเอกสารรายงาน):
รายวิชา | จำนวนผู้สมัครสอบ | สอบผ่าน (คน, ร้อยละ) | สอบไม่ผ่าน (คน, ร้อยละ)

ระบบมีตารางรายวิชาอยู่แล้วที่ [reportsReal.jsx:188](../../../frontend/src/design/reportsReal.jsx#L188)
แต่ยังใช้แทนเอกสารไม่ได้ เพราะต่างกัน 4 จุด:

1. ไม่มีคอลัมน์ "จำนวนผู้สมัครสอบ"
2. ตัวหารเป็น "คนที่สอบวิชานั้น" ไม่ใช่นักศึกษาทั้งรุ่น → ร้อยละไม่ตรงกับเอกสาร
3. ร้อยละปัดเป็นจำนวนเต็ม (89%) เอกสารต้องการ 2 ตำแหน่ง (89.42%)
4. ช่องสอบไม่ผ่านมีแต่จำนวนคน ไม่มีร้อยละ

## ขอบเขต

ทำ **ตารางอย่างเดียว** ไม่สร้าง donut/bar chart ใหม่
เพราะข้อมูลของ donut มีอยู่แล้วใน `PassDistribution` และของ bar มีอยู่แล้วใน `SubjectRateCard`
สร้างใหม่ = ข้อมูลซ้ำ ไม่ได้ข้อมูลเพิ่ม

ตารางนี้แสดง 2 ที่ ใช้ component ตัวเดียวกัน:
- หน้ารายงาน (`reportsReal.jsx`) — ต่อจากตารางรายวิชาเดิม
- Dashboard แท็บใหม่ "ผ่านครั้งแรก รายวิชา" ทั้งเจ้าหน้าที่และผู้บริหาร

ข้อมูลมาจาก **รอบสอบครั้งที่ 1 (attempt_number = 1) ของปีที่เลือก** เท่านั้น
ปีเลือกจากตัวเลือกปีที่มีอยู่แล้วในแต่ละหน้า ไม่เพิ่ม picker ใหม่

นอกขอบเขต (ก้อนที่ 2 หลังก้อนแรกเสร็จ): ยกตารางนี้ลง PDF report

## กติกาการนับ

3 ช่องผลลัพธ์ต่อ 1 รายวิชา บวกกันแล้วต้องเท่ากับจำนวนผู้สมัครสอบเสมอ

| ช่อง | นับจาก |
|---|---|
| จำนวนผู้สมัครสอบ | `total` = นักศึกษาทั้งรุ่นของปีนั้น (เลขเดียวกันทุกแถว เช่น 208) |
| สอบผ่าน | คนที่กรอกว่าผ่านวิชานั้นในรอบแรก |
| สอบไม่ผ่าน | **เฉพาะคนที่กรอกว่าตกจริง** ไม่กลืนคนที่ไม่ได้ส่งผลเข้ามา |
| ยังไม่ส่งผล | `ผู้สมัครสอบ − ผ่าน − ไม่ผ่าน` คิดรายวิชา ไม่ใช่รายคน |

ทุกร้อยละหารด้วย `total` ทศนิยม 2 ตำแหน่ง → **ร้อยละ 3 ช่องรวมกันได้ 100.00 ทุกแถว**

ทำไมแยกคอลัมน์ "ยังไม่ส่งผล" แทนที่จะยุบเข้าช่องไม่ผ่านแบบเอกสาร:
- แถวบวกได้ครบ ตรวจง่าย เห็นทันทีว่าเลขไม่หาย
- นักศึกษากรอกบางวิชาแล้วค้างไว้ได้ วิชาที่ค้างเยอะจะโผล่ให้เจ้าหน้าที่เห็นทันที
- ตอน export PDF (ก้อนที่ 2) ค่อยยุบเข้าช่องไม่ผ่านให้ตรงเอกสารทางการ
  บนจอเห็นความจริง ในเอกสารเห็นแบบทางการ

สมมติฐาน: รอบสอบครั้งที่ 1 ไม่มี `carried_forward` (ไม่มีรอบก่อนหน้าให้ยกผลมา)
วิชาที่ไม่มีใครสอบเลย (pass = fail = 0) แสดง `—` ไม่ใช่ `0.00%`

## Backend

ไม่เพิ่ม endpoint ใหม่ ไม่แตะ schema
เพิ่ม field เดียวใน `buildYearSummary()` ที่ `backend/src/modules/dashboard/dashboard.service.js`
ซึ่ง `/dashboard/history` ส่งออกอยู่แล้ว

คำนวณจาก `firstRoundSent` + `firstRoundSubjectIds` ที่ฟังก์ชันเก็บไว้อยู่แล้ว
ต้องกรองใบที่ถูกตีกลับด้วย `notRejected()` ให้ตรงกับกฎเดิมของทั้งไฟล์

```js
firstAttemptBySubject: {
  cohort_total: 208,        // = total ของปี (คอลัมน์ "ผู้สมัครสอบ")
  submitted: 200,           // คนที่ส่งผลรอบแรก — ใช้เขียนกำกับใต้ตาราง
  average_pass_rate: 96.60, // ค่าเฉลี่ย pass_rate ของวิชาที่มีคนสอบ — ใช้เป็นเส้นอ้างอิงสี
  subjects: [
    {
      subject_id, subject_code, subject_name,
      pass: 186,          pass_rate: 89.42,          // pass / cohort_total
      fail: 14,           fail_rate: 6.73,           // fail / cohort_total
      not_submitted: 8,   not_submitted_rate: 3.85,  // cohort_total − pass − fail
      sat: 200,                                       // pass + fail; 0 = ไม่มีใครสอบวิชานี้
    }
  ]
}
```

- ใช้ `rate2()` ที่มีอยู่แล้วในไฟล์ ไม่ใช่ `percent()` (ต้องได้ 89.42 ไม่ใช่ 89)
- 3 rate ของแต่ละวิชาต้องรวมได้ 100.00 — ถ้าเศษการปัดทำให้เพี้ยน ยกเศษไป
  `not_submitted_rate` (ช่องที่คนอ่านสนใจน้อยสุด) ไม่ปล่อยให้รวมได้ 99.99
- เรียงตาม `subject_code` น้อยไปมาก (ตรงกับเอกสาร) การเรียงแบบอื่นทำที่ frontend
- `firstAttemptBySubject: null` ถ้าปีนั้นไม่มีรอบ attempt_number = 1

อัปเดต `backend/BACKEND_GUIDE.md` (response shape ของ `/dashboard/history`) + Changelog
ในคอมมิตเดียวกัน ตามกฎใน CLAUDE.md

## Frontend

component ใหม่ `FirstAttemptSubjectTable` ใน `frontend/src/design/components.jsx`
(ไฟล์ที่ทั้ง `dashboardReal` และ `reportsReal` import อยู่แล้ว)

รับ prop: ก้อน `firstAttemptBySubject` + `academic_year` + `lang` + `tt`
ไม่คำนวณ % เองแม้แต่ตัวเดียว — หยิบจาก backend มาวาดอย่างเดียว

```
┌─ สรุปผลสอบผ่านครั้งแรก จำแนกรายวิชา · ปีการศึกษา 2567    [เรียง: รหัสวิชา ▾] ┐
│ รายวิชา              ผู้สมัคร   สอบผ่าน       สอบไม่ผ่าน    ยังไม่ส่งผล        │
│                       (คน)  จำนวน    %    จำนวน    %   จำนวน    %           │
│ 1101 การผดุงครรภ์      208   186  89.42     14  6.73     8  3.85 ▓▓▓▓▓▓░▒   │
│ 1102 การพยาบาลมารดาฯ   208   200  96.15      0  0.00     8  3.85 ▓▓▓▓▓▓▓▒   │
│ …                                                                          │
│ รวมทุกวิชา           1664  1548  93.03     50  3.00    66  3.97           │
│ ⓘ จากนักศึกษาทั้งรุ่น 208 คน · ส่งผลรอบแรกแล้ว 200 คน                       │
└────────────────────────────────────────────────────────────────────────────┘
```

- คอลัมน์ตรงกับเอกสารสภาการพยาบาล + คอลัมน์ "ยังไม่ส่งผล" เพิ่มมา
- mini bar ท้ายแถว: แถบเดียวแบ่ง 3 ท่อนตามสัดส่วน (เต็มความกว้าง = ผู้สมัครสอบ)
  เริ่มที่ 0 เสมอ ไม่ตัดฐานแกน — ตัดฐานทำให้ 93% กับ 98% ดูห่างกันเป็นเท่าตัว
- ปุ่มสลับการเรียง: รหัสวิชา (ค่าเริ่มต้น ตรงเอกสาร) ⇄ % ผ่านน้อยไปมาก (หาวิชาที่ต้องแก้)
- แถวที่ `pass_rate < average_pass_rate` พื้นหลังอ่อนๆ
  (ไม่ใช้เกณฑ์ตายตัว 90% — ปีที่ผลดีจะไม่ติดเลย ปีที่แย่จะติดทั้งตาราง)
- แถวรวมท้ายตาราง + บรรทัดกำกับตัวหารใต้ตาราง (ทำแบบเดียวกับ `PassDistribution` เดิม)

สี: ใช้ token เดิม `--pass` / `--fail` / `--ink-200` (ยังไม่ส่งผลเป็นเทากลางๆ ไม่ใช่สีเตือน)
แถวต่ำกว่าเฉลี่ยใช้ `--fail` แบบโปร่ง ไม่เพิ่มสีใหม่

## เคสที่ต้องกันพัง

| เคส | ต้องแสดง |
|---|---|
| ปีนั้นยังไม่มีรอบที่ 1 (`firstAttemptBySubject === null`) | "ยังไม่มีข้อมูลการสอบรอบแรกของปีนี้" |
| วิชาที่ไม่มีใครสอบ (`sat === 0`) | ช่องผ่าน/ไม่ผ่านขึ้น `—` ยังไม่ส่งผล 100% mini bar เทาทั้งแถบ |
| ไม่มีใครส่งผลเลย (`submitted === 0`) | ทุกแถวยังไม่ส่งผล 100% |
| `cohort_total === 0` (ยังไม่ import นักศึกษา) | ข้อความว่าง ไม่หารด้วย 0 |

## การตรวจว่าถูก

1. ทุกแถว: `pass + fail + not_submitted = cohort_total` เป๊ะ
2. ทุกแถว: `pass_rate + fail_rate + not_submitted_rate = 100.00` เป๊ะ
3. `pass` ของแต่ละวิชา เท่ากับที่ `SubjectRateCard` แสดงสำหรับรอบแรกปีเดียวกัน
4. `cohort_total` เท่ากับ `total` ที่ `PassDistribution` ใช้เป็นตัวหาร (ตารางบนหน้าเดียวกันต้องหารตัวเดียวกัน)
5. เทียบกับตารางในเอกสารรายงานปี 2567 ทีละบรรทัด — ช่อง "สอบไม่ผ่าน" ในเอกสาร
   ต้องเท่ากับ `fail + not_submitted` ของเรา
